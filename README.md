# BOYDS — Independent Community Guide

A responsive starter website for Boyds, Maryland, built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and starter content
- `styles.css` — responsive design
- `script.js` — mobile navigation, event filtering, directory search/filtering, and demo suggestion form

## Run it
1. Unzip the folder.
2. Open `index.html` in a modern browser. Internet access is needed for Google Fonts and remote images.
3. For a more realistic local development setup, open the folder in VS Code and use a simple local server extension.

## Important notes before publishing
- This is an independent project, not an official government or county website.
- Event rows are organizer pointers, not confirmed dated listings. Check the linked organization before advertising an event as upcoming.
- Verify business details, park information, transit schedules, and all contact details before publication.
- The suggestion form stores data in localStorage on the visitor's device only. It does not submit data to a server and is not a live submission system.
- Remote Unsplash images are illustrative placeholders. Replace them with original or properly licensed Boyds-area photos before launch.
- To publish real news or accept submissions from visitors, add a backend or connect a form service and moderation workflow.


Photo note: This version uses real Boyds-area photographs hosted on Wikimedia Commons, so you do not need to download image files separately. The photos require an internet connection to load.
